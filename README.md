# devmeet

개발자와 개발자를 만나고 싶은 사람에게 매일 세 명을 소개하는 소개팅 서비스입니다.

**서비스 바로가기: https://devmeet.zmint.dev**

## 폴더

| 폴더 | 내용 |
| --- | --- |
| [`frontend`](frontend) | 화면 (React, Vite, Tailwind) |
| [`backend`](backend) | 서버 (Spring Boot, MySQL) |
| [`docs`](docs) | 제품 명세 ([MVP v0.1](docs/MVP-v0.1.md)) |

main에 병합되면 자동 검사를 거쳐 위 주소로 바로 배포됩니다.
